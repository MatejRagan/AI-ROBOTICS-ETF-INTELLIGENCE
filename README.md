# AI & Robotics ETF Intelligence

Interactive single-page analysis of European UCITS AI and robotics ETFs, semiconductor packaging bottlenecks (CoWoS/HBM), data-centre power constraints, the AI capex gap, and EU/Slovak tax considerations.

## Open the page

- **Live site:** [AI & Robotics ETF Intelligence](https://matejragan.github.io/AI-ROBOTICS-ETF-INTELLIGENCE/)
- **Local preview:** open `index.html` in a browser, or run `python3 -m http.server 8000` in the repository directory and visit <http://localhost:8000>.

The page loads Tailwind CSS, Chart.js, Plotly, and Google Fonts from public CDNs, so an internet connection is required for the full visual experience.
